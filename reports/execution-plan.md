# 执行计划

## 核心假设（已验证）

> 对原图做边缘约束平滑 + 色调分离后，导入"画像素"等工具的像素化质量明显优于直接导入原图。

---

## 策略：最小可验证原型优先

不一次性做完整工具，先用最少代码验证核心算法效果，再逐步完善 UI 和功能。

```
MVP（验证算法）→ 功能完整版（完善交互）→ 打磨（细节优化）
```

---

## 阶段一：核心算法验证 ✅ 已完成

核心假设已验证：简化后的图导入像素画工具，效果优于原图。

---

## 阶段 1.5：风格参数探索 ✅ 已完成

用 Python 批量生成约30种参数变体，用户目视选出最佳参数，固化到工具中。

4种风格参数详见 CLAUDE.md §2-3。

**v0.1 已实现：** 4种风格并排输出（2×2网格），单文件网页工具 + CLI 批处理脚本。

---

## 阶段二：完整交互 UI（当前阶段）

**目标：** 实现 CLAUDE.md 规格中描述的3阶段工作流——轮廓确认 → 图像简化 → 输出。

### 任务清单

| # | 任务 | 验收标准 |
|---|------|----------|
| 2.1 | Sobel 边缘检测 + 青色叠加预览 | 边缘线清晰显示在原图上 |
| 2.2 | 阈值滑块 + 实时预览（150ms 防抖）| 滑动阈值，边缘线实时变化 |
| 2.3 | 确认轮廓按钮 → 进入简化阶段 | 端到端流程可用 |
| 2.4 | 4种风格选择 + 色阶滑块 + 实时预览 | 切换风格后处理结果实时更新 |
| 2.5 | 分屏对比预览（可拖拽分隔线）| 左右拖动分隔线，实时对比原图/处理图 |
| 2.6 | 下载 PNG + 复制到剪贴板 | 能保存/粘贴到画像素等工具 |

### 测试方法

- 上传人物照片 → 调阈值 → 确认轮廓 → 选风格 → 下载 → 导入画像素，验证端到端流程
- 对比4种风格输出与原图的像素化效果差异

## 阶段三：手动描画 + 细节完善

**目标：** 让用户能手动修正边缘检测结果。

### 任务清单

| # | 任务 | 验收标准 |
|---|------|----------|
| 3.1 | 手动描画模式（绘制/擦除/笔刷大小）| 能在边缘图上手动增减边缘线 |
| 3.2 | 阶段状态机（阶段1 ↔ 阶段2 切换）| 按钮切换流畅，状态不混乱 |
| 3.3 | 平滑强度滑块（0–10）| 调参后处理结果实时更新 |

### 测试方法

- 完整走一遍"上传→调阈值→手动修正→确认→调参→下载"，记录卡顿/困惑点
- 边界情况：超大图（>4000px）、超小图（<100px）、透明 PNG

## 测试图片准备

建议准备以下类型各 1–2 张：

| 类型 | 原因 |
|------|------|
| 人物半身照（真实照片）| 最常见使用场景，肤色渐变是最大挑战 |
| 卡通/动漫截图 | 验证对已简化图片是否有帮助或反效果 |
| 动物照片（毛发细节多）| 高频纹理，平滑算法压力测试 |
| 风景/建筑（几何边缘清晰）| 边缘检测效果验证 |

## 风险与退出条件

| 风险 | 退出/调整条件 |
|------|--------------|
| 双边滤波性能太差 | 处理时间 > 10秒 → 降级为高斯模糊 + 边缘锐化替代 |
| 与 AI 工具效果差距太大 | 考虑专注"离线/可控"差异化而非效果竞争 |
