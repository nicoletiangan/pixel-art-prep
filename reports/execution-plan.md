## 阶段三：适配移动端（当前阶段）

**目标：** 让工具在手机浏览器上可用，覆盖上传、边缘检测、风格生成、下载全流程。

### 设计决策

| 决策 | 选择 |
|------|------|
| 面板布局 | A2 — 面板置顶，预览区在下，`< 600px` 断点切换 |
| 阶段2网格 | B2 — 保持2×2，点击任意格子全屏放大预览，点击关闭 |
| iOS下载 | C1 — 检测到 iOS 时弹模态框，提示「长按图片→存储图像」|

### 执行步骤

**Step 1 — viewport 与 body 基础修复**（低复杂度，无风险）
- `viewport` meta 补充 `viewport-fit=cover`
- `body` 高度改为 `100dvh`（兼容写法保留 `100vh` 作 fallback）
- 底部加 `env(safe-area-inset-bottom)` 防 iPhone Home 条遮挡

**Step 2 — 响应式布局重构**（中复杂度，中风险）
- 断点 `< 600px`：`.workspace` 改为纵向排列
- `.panel` 变为顶部横向滚动条（各控制区横向排列，`min-width: 160px`）
- `.preview-area` 占剩余高度
- 阶段1画布、阶段2网格内允许滚动

**Step 3 — 触控描画支持**（低复杂度，低风险）
- `#cv-stage1` 加 `touch-action: none`（CSS 层面阻止触摸滚动）
- 已有 pointer events，触摸笔刷逻辑不变

**Step 4 — 阶段2格子点击放大预览**（中复杂度，低风险）
- 点击任意风格卡的图片区域 → 弹出全屏遮罩显示该图片
- 点击遮罩关闭；不含原图对比（非分屏，仅放大单张）

**Step 5 — iOS 下载降级**（低复杂度，低风险）
- 下载函数改为 `canvas.toBlob() + URL.createObjectURL()`
- 检测 iOS：弹模态框提示「长按图片→存储图像」，模态框复用现有组件

**Step 6 — 剪贴板降级文案适配**（低复杂度，无风险）
- 模态框提示文案根据平台动态切换：
  - iOS：「长按图片，选择『存储图像』或『复制』」
  - Android：「长按图片，选择『复制图片』」
  - 桌面：「右键图片，选择『复制图片』」（现有文案）

### 测试方法

#### 方式1：浏览器 DevTools 模拟（快速，2分钟）

1. 用 Chrome 或 Edge 打开 `pixel-art-tool.html`
2. 按 `F12` 打开 DevTools
3. 点击工具栏手机图标（或 `Ctrl+Shift+M`）切换设备模式
4. 顶部选择设备，如 `iPhone 12 Pro`（390px 宽）
5. 刷新页面

可验证布局、按钮大小、点击放大等。触摸事件为模拟，不完全等同真机。

#### 方式2：真机测试（最准确）

在项目目录启动临时 HTTP 服务器：

```bash
python -m http.server 8080 --directory C:/ClaudeCode/pixel-art-prep
```

手机与电脑连同一 Wi-Fi，手机浏览器访问：

```
http://<电脑局域网IP>:8080/pixel-art-tool.html
```

查电脑 IP（Windows）：

```bash
ipconfig
# 找「IPv4 地址」，通常为 192.168.x.x
```

可验证真实触控、iOS 下载降级、剪贴板行为等。

## 测试图片准备

建议准备以下类型各 1–2 张：

| 类型 | 原因 |
|------|------|
| 人物半身照（真实照片）| 最常见使用场景，肤色渐变是最大挑战 |
| 卡通/动漫截图 | 验证对已简化图片是否有帮助或反效果 |
| 动物照片（毛发细节多）| 高频纹理，平滑算法压力测试 |
