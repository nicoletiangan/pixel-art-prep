# 测试计划 v1 — 阶段一 & 1.5 完善验证

## 目标

在进入阶段二（完整交互 UI）之前，验证当前4种风格算法在**不同类型图片**上的表现，确认算法参数是否需要调整。

---

## 测试图片矩阵

需准备5类图片，每类 1–2 张，共 5–10 张。

| 类别 | 代号 | 说明 | 关键挑战 |
|------|------|------|----------|
| 真人照片 | `photo-person` | 真实人物半身照/头像 | 肤色渐变、发丝细节 |
| 实际风景照片 | `photo-landscape` | 户外真实场景（山/海/城市）| 天空渐变、大面积纹理 |
| 风景画/插画 | `illust-landscape` | 数字绘画或水彩风景 | 已有色块风格，验证是否过度处理 |
| 人物画像/插画 | `illust-person` | 写实/半写实人物插画 | 阴影层次、线稿结构 |
| 卡通/动漫 | `anime` | 日系动漫截图或卡通图 | 已有描边，验证是否冲突 |

> 现有：`Julie-Sweet-2.jpg` → 归类为 `photo-person`（已有基线数据）

---

## 图片来源建议

请自行准备或从以下免版权来源获取：

- **真人照片** — Unsplash (`unsplash.com`)，搜索 portrait
- **风景照片** — Unsplash，搜索 landscape
- **风景画** — WikiArt 公版画作，或 Pixiv 免费插画
- **人物画像** — WikiArt，或概念艺术网站
- **卡通/动漫** — 游戏官网宣传图、动画截图（自有素材）

建议尺寸：500–1500px 宽，避免超大图（首轮测试不考虑性能）

---

## 评估矩阵

对每张图片 × 4种风格，逐项打分（1–5分，1=差，5=优）：

| 评估维度 | 说明 |
|----------|------|
| **色块干净度** | 平涂区域是否均匀，无杂色噪点 |
| **轮廓清晰度** | 主体边缘是否清晰，不模糊不断裂 |
| **色彩自然度** | 颜色是否忠实原图，无明显色相偏移 |
| **像素化适合度** | 导入画像素等工具后，效果是否优于原图直接导入 |

> "像素化适合度"是**最重要指标**，其他三项服务于这一目标。

## 执行步骤

### 步骤 1：准备图片
将各类图片放入 `testresources/input/`，文件名使用代号：
```
photo-person-1.jpg    （Julie-Sweet-2.jpg 改名或新增）
photo-landscape-1.jpg
illust-landscape-1.jpg
illust-person-1.jpg
anime-1.jpg
```

### 步骤 2：批量生成简化图
```bash
# 对每张图片运行4种风格处理
python process.py testresources/input/photo-landscape-1.jpg testresources/output/photo-landscape-1 --levels 4
python process.py testresources/input/illust-landscape-1.jpg testresources/output/illust-landscape-1 --levels 4
python process.py testresources/input/illust-person-1.jpg testresources/output/illust-person-1 --levels 4
python process.py testresources/input/anime-1.jpg testresources/output/anime-1 --levels 4
```

输出：每张图生成4个 PNG（写实/卡通/抽象/复古）

### 步骤 3：像素化对比
对每张图片，将**原图**和**4种简化图**分别导入"画像素"（或同类工具），使用相同像素化设置（同一目标分辨率），截图保存。

比较：简化后导入的效果 vs 原图直接导入的效果

### 步骤 4：记录结果
填写评估表（见下方模板），标注每种图片类型中哪种风格效果最好/最差。

## 通过标准

| 判断 | 条件 |
|------|------|
| ✅ 算法稳定，进入阶段二 | 5类图片中，至少4类有1种风格明显优于原图直接像素化 |
| 🔧 局部调整参数 | 某1–2类图片效果差，其他类正常 → 对该类型调整参数后复测 |
| ❌ 重新审视算法 | 超过2类图片所有风格均无改善 |

---

## 预期风险

| 图片类型 | 潜在问题 | 预案 |
|----------|----------|------|
| 卡通/动漫 | 原图已有描边，卡通风格的自适应暗化描边可能叠加显得过重 | 动漫图考虑使用写实/抽象风格 |
| 风景画 | 原图已是简化风格，可能过度处理导致色彩失真 | 降低色阶分离强度（--levels 6）|
| 风景照片 | 天空大面积渐变，pixelate 抽象风格可能产生大色块跳变 | 可接受，抽象风格本身定位如此 |
